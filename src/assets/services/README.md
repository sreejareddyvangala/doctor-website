# Service images

## ➜ To add real photographs, use the `photos/` subfolder

Do **not** edit the SVGs below. Drop your photographs into `photos/` named after the
service slug and they override these illustrations automatically — no code changes.
See `photos/HOW-TO-ADD-PHOTOS.md`.

---

## Fallback illustrations

The files below are the fallbacks used until a photograph exists for that service.

| File                          | Service                |
| ----------------------------- | ---------------------- |
| `knee-replacement.svg`        | Knee Replacement       |
| `hip-replacement.svg`         | Hip Replacement        |
| `arthroscopy.svg`             | Arthroscopy            |
| `trauma-care.svg`             | Trauma Care            |
| `pelvic-surgery.svg`          | Pelvic Surgery         |
| `complex-trauma-surgery.svg`  | Complex Trauma Surgery |

These are purpose-drawn anatomical illustrations, not photographs. They deliberately
avoid depicting identifiable people or implying clinical results.

## Recommended specs for photographs

- **Aspect ratio:** 4:3 (cards crop to a fixed 4:3 box with `object-fit: cover`, so
  anything close works and nothing is stretched or distorted)
- **Size:** 1200 × 900 px is plenty; keep files under ~250 KB
- **Format:** `.jpg` or `.webp`
